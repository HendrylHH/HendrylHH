## O que documentar

Cada trabalho deve apresentar o problema, o SGBD e sua versão, o esquema, a origem dos dados e os passos para reproduzir as consultas. Prefira dados sintéticos gerados por script; não publique exportações de bancos profissionais.

Em otimizações, registre consulta inicial, plano de execução, alteração proposta e condições de medição. Explique os custos dos índices e as limitações do teste, sem extrapolar resultados locais para produção.

Scripts que removem tabelas ou recriam o banco precisam de aviso explícito e devem apontar apenas para um ambiente descartável de demonstração.
