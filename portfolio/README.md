## Como os projetos são organizados

Laboratórios menores ficam em `portfolio/<area>/<nome-do-projeto>/`, com README e arquivos próprios. Aplicações completas e ferramentas reutilizáveis podem permanecer em repositórios independentes, referenciados nos índices.

Um projeto pode aparecer em mais de uma área, mas seu código deve ter uma única origem. Links cruzados destacam competências diferentes sem duplicar a implementação.

Não há projetos de exemplo implementados nas pastas vazias. Os catálogos serão atualizados conforme trabalhos reais forem adicionados e documentados.
