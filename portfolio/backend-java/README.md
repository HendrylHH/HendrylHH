## O que documentar

Explique o problema, os contratos da API, as validações, o modelo de dados e o tratamento de erros. Registre as versões do JDK e das dependências, os comandos de execução, as migrações e como rodar os testes.

Concorrência, processamento assíncrono, autenticação e integração com LLMs devem ser descritos somente quando realmente implementados. Frameworks não utilizados não devem aparecer como parte da stack.
