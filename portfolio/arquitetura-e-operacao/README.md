## O que documentar

Apresente contexto, restrições, alternativas consideradas, decisão e consequências. Sempre que possível, aponte para um projeto público que permita verificar a implementação.

Estudos de operação devem distinguir procedimentos documentados de procedimentos realmente executados. Benchmarks devem informar ambiente, configuração, método, dados e limitações.

Diagramas e relatos precisam representar sistemas próprios de demonstração, sem copiar topologias, incidentes, identificadores ou configurações de ambientes profissionais. Use o [modelo de README](../../templates/README-PROJETO.md), adaptando as seções ao estudo.
